# Data provenance, rights, and ethics

- Use only public NCBI genome assemblies and **non-identifying** metadata with verified accession/version and source attribution.
- Document original BioProjects, sequence submitters, publications, software citations, retrieval dates, and inclusion/exclusion criteria.
- Public access does not guarantee absence of sampling bias or authorization to disseminate derived, person-linked metadata.
- Do **not** upload unpublished clinical sequencing data, patient identifiers, protected collaborators' materials, or restricted data.
- The `.gitignore` excludes raw FASTA/FASTQ and large intermediate files, local accession manifest, analysis results, and downloads. This is not a substitute for checking git status before commit.
- Disclose whether an output was derived from a published reference, a training fixture, or a new computational analysis.
- For any non-public material, obtain explicit institutional authorization before sharing or running it in a public service.
